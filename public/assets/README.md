# Assets

Place final website media assets here.

## Folders

```text
brand/       UMMA logo, wordmark, icon
photos/      robot, fabrication, mechanism photos
videos/      demo and test videos
slides/      exported PPT decks or PDF slide files
technical/   UI screenshots, telemetry, plots, maps
cad/         CAD renders, exploded views, drawing previews
diagrams/    architecture and data-flow diagrams
```

Keep original high-quality files outside the repo if they are too large. For the website, use compressed web-ready copies.
