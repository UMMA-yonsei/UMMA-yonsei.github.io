Gripper

Granular jamming mechanism을 이용한 형상 적응형 소프트 그리퍼입니다. Soft membrane, granular medium, pressure control, wrist rotation, and servo actuation are combined for object-adaptive grasping.

UMMA_WS Hardware

Mechanical Structure

기어, finger, bearing bracket, rail, case, camera/siren accessory mount가 분리된 부품으로 관리됩니다.

  • Finger pair for left/right grasping
  • Wrist rotation axis for object orientation
  • Pump servo path for suction operation
  • CAD assemblies and drawing exports for fabrication

Control Interface

서보 제어는 `umma_hardware_interface`와 Web UI button action을 통해 연결됩니다.

  • `l_gripper`, `r_gripper` for grasping
  • `l_wrist`, `r_wrist` for wrist rotation
  • `pump` for valve position
  • Mobile app IMU mapping for wrist target control
