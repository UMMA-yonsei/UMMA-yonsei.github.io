ROS 2 Robot Stack

Edge device, ROS 2 packages, motor drivers, Arduino bridges, camera, LiDAR, web API, and mobile control are connected as one robot operation stack.

ROS Workspace Web Frontend Mobile App

Data Flow

Operator UI, REST command bridge, ROS topic/service interface, low-level controller가 단계적으로 연결됩니다.

  • Browser or Android app sends operation request
  • `umma_web_ui` validates session and command policy
  • ROS bridge publishes topics or calls services
  • Motor, Arduino, servo, speaker, camera nodes execute hardware behavior

Safety Layer

Command gates, emergency stop state, zero velocity command, actuator stop command가 운용 경로에 포함됩니다.
